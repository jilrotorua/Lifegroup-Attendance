JIL LIFEGROUP APP UPDATE

Upload every file in this update ZIP to the ROOT of your existing GitHub repository.
When GitHub asks, confirm that the existing files should be replaced/overwritten.

This update adds:
- Multiple Lifegroups per leader
- Separate members and attendance for each Lifegroup
- All Members view with Lifegroup cards and birthdays
- Easier Day / Month / Year birthday entry
- Up to five resized gathering photos
- Sent gatherings remain in Attendance History
- Photos appear in the Church Admin dashboard
- A separate Visitors database for every Lifegroup
- First-time and returning visitor records with gender, birthday, mobile and inviter
- Named visitors can be selected when recording attendance
- First-time visitors automatically become returning after their first recorded visit
- Visitor birthdays appear on the Home screen with a Visitor label

After uploading, wait 1–3 minutes and refresh the app. If the old version remains,
close the app tab and reopen the GitHub Pages link.

The database has not been configured yet. When setting it up, use the updated
schema.sql and worker.js included here.
